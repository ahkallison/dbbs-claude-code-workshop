Read the scripts in scripts/, results/versions.txt and results/commands.log.
Write a methods paragraph suitable for a paper. Name every tool and its
version, the normalization, the statistical test, the multiple-testing
correction and the significance thresholds.

Use only facts you find in these files. If something a reviewer would ask
about is missing, list it under "Missing information" instead of guessing.

Save the result to results/methods.md.
